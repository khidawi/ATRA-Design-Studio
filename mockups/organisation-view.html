Questions to settle before building

    
    
      
  1. One organisation per ASTRA install, or several (for a consultancy managing client companies)?
    2. 
      
  2. People: named individuals, roles ("Support agents"), or both? The mockup allows both.
    3. 
      
  3. Task links between agents: declared in the Agent studio (as today's delegations) and shown here, or drawn here and pushed into the studio? The mockup assumes one model, edited from either side.
    4. 
      
  4. Cross-department links: should one need acceptance by the other agent's owner before a contract can be ratified? Should the data passed be modelled and checked against a policy?
    5. 
      
  5. Which Sectro views do you want: Organisational view, Data mapping, Privacy by design, Data breach response plan? The mockup shows the first two and adds Agents & tasks and Models; Privacy by design (threats, mechanisms, measures) and breach response could follow.
    6. 
      
  6. Which element types should the toolbar offer? The palette shows Sectro's (organisation, actor, goal, operation, policy, asset) plus ours (department, AI agent, AI model, data store).
    7. 
      
  7. HR export (CSV) and directory sync (Entra ID, Okta, LDAP) later, so IDs match real employee IDs?
    8. 
      
  8. Who may edit the organisation: administrators only, or compliance as well?
